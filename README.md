# Velocity Auto

Velocity Auto is a Burnaby, BC mechanic shop and auto service center specializing in preventative maintenance, diagnostics, and reliable repairs for daily drivers, work vehicles, and performance builds.

## Run locally

Open `index.html` in a browser, or serve the folder with a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
